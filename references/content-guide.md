# Content guide

## 用途与范围

本文件支持英语学习笔记的 **workflow Skill**：从用户当前提供的英语材料读取、理解、逐句讲解，再交给排版和验证流程。它不是可直接套用的成品模板图库，也不保存可用于替代新材料的固定答案。

默认保留用户明确偏好：完整中文翻译、详尽考点解析、彩色标注、箭头指引、趣味图解；正文中的 Grammar 术语用 English，并在集中词汇表中提供中英对照。默认交付 PDF 与可离线使用、支持自测、搜索和跳转的 HTML；当前用户另有明确要求时以当前要求为准。

## 先建立原文清单

- 实际读取本次附件或用户指定文件，核对页数、题号、句子、标题、括注和选项；无法读取的部分明确标记，不假装已取得内容。
- 按原顺序建立稳定 `id` 与来源页码。保留一份逐字原文；清理分页断行时不得合并独立题目或丢掉否定、标点、脚注。
- 数量、分组、词义地图、Grammar glossary 条目都由本次文件推导，不能复用某次项目的固定句数、分类数或术语数。
- 图片或扫描件先核对 OCR，尤其是编号、连字符、所有格、同形词、否定词；不确定的字符回看原图。
- 原文若有真实题目与选项，全部翻译并按题目类型讲解；原文只有例句时，不擅自增编选择题或声称有标准答案。

## 每句的数据契约

每项含稳定 `id`、已核对原句 `english`、保留提取信息的 `raw`、来源页码 `page`，以及下列字段。数组数量是常见起点，应随句子复杂度调整，不能为凑数量重复同义解释。

| 字段 | 类型 | 内容要求 |
| --- | --- | --- |
| `translation` | string | 自然、准确的完整中文译文，保留时态意义、情态强度、否定、数量、范围和逻辑。 |
| `structure` | string[] | 通常 2—3 项；找 sentence core，拆 Clause、Nonfinite verb、Modifier、Adverbial，并解释它们修饰谁、作用于什么。 |
| `vocabulary` | object[]（兼容旧string[]） | 通常 3—4 项；核心词的本句 part of speech、具体义项、搭配，以及逐项的 Near synonyms 与 Usage note。格式见 schema.md。 |
| `exam_points` | string[] | 通常 2 项；指出本句实际可考的翻译、语法或辨析方式，并说明判断依据。 |
| `pitfalls` | string[] | 通常 1—2 项；具体错误读法、错误原因与正确理解，避免泛泛写“注意理解”。 |
| `source_note` | string | 正常为空；原文确有语法、搭配、事实概括或术语问题时，独立说明并给审慎改写。 |
| `diagram` | object[] | 通常 3—4 格，每项 `{role, text}`；`text` 取自原句，`role` 表真实句法或逻辑关系。 |
| `memory_tip` | string | 一句准确、具体的记忆钩子，可用箭头、类比和反例；不能编造词源。 |

标题另设简短 `keyword`，人工确认是本句目标单词或搭配；不能直接拿整条 `vocabulary` 文本当标题。

## 逐项近义联想

- Vocabulary 与 Lexical Resources 采用相同标准：每项先解释原词，再选贴合本句义项的近义 Words or Phrases，通常1至3个，不机械凑数。
- 比较对象保持同一义项与语境。优先给可对应的搭配或短语，如 `provoke opposition → arouse opposition`；词性或句式发生变化时，在 Usage note 明确说明。
- 每个近义表达都附简短辨析，交代程度、语体、语气、典型搭配或替换限制。不要把‘意义相近’写成‘完全相同’；用‘近义’或‘可意译为’，不滥用等号。
- 同主题词、反义词、上下位词和相关概念不冒充近义词。专业名词没有可用的近义词时，允许准确释义短语，并说明这只是解释性改述；否则写明没有合适近义表达的原因。
- 保留原材料括注的有效义项，纠正错误义项时独立说明。新增表达以本句为依据，不复制固定同义词清单，不混用原词的其他义项。
- 合并后逐项检查：词条、原义、近义表达、辨析都进入PDF和HTML；没有合适表达的词条具有实际原因。

## 逐句推导与边界

- 先自己还原句法和语义，再写解析；不能仅根据单词列表自动填充句型说明。
- 主谓一致找 Subject head word；不要被邻近的复数名词、插入语或 `of` 短语误导。
- 区分 finite Predicate 与 Nonfinite verb，说明省略结构的逻辑 Subject，指出 Relative clause 的 Antecedent。
- `to do` 表目的不自动证明目的已实现；`decide/agreed to do` 不等于行动已经完成；`can/may` 不译成必然。
- 保留 `some`、`several`、`under ... conditions` 等范围限制；不能把部分对象、特定条件推广为全部情况。
- 词义必须贴合搭配和领域；如 `terminal examinations` 可在教育语境表示期末考试，不能机械套用医疗义项。
- 词形相近不等于意义相同；如 `negligent/negligible`、`exclude/exclusive` 应说明 part of speech 与适用对象。
- 不可数与单复数同形分别解释：`prey` 的不可数用法不等于 `offspring/species` 的单复数同形规则。
- 非标准术语先标明不确定性；不能把近似短语直接等同于某一科学机制，也不要为语言练习补造事实背景。
- 不把一般可能考查点写成未经证实的“历年必考”“最高频”；若引用外部真题频率，必须有可核对来源。

## 原文有瑕疵时

保留 `english` 和 `raw`，按可辨认的原意提供翻译；把判断、说明和自然改写放入 `source_note`，明确标注“原句说明／建议改写”。改写不能冒充原文，也不能默默改变原文的数量、语气、时间或因果。

区分“不合语法”“搭配略生硬”“术语依语境可用”“事实概括过强”，不要把单纯风格偏好判成绝对错误。若存在合理的不同分析，给出本次采用的分析及简短理由。

## Grammar language 与图解

- 正文的术语标签使用 English，例如 Subject、Predicate、Object、Complement、Modifier、Adverbial、Relative clause、Infinitive；解释内容仍以中文为主。
- 建立集中 Grammar glossary：English → 中文名称 → 简明解释 → 本次对应例句编号，覆盖正文实际出现的术语。
- 术语转换应逐处判断，不对整份中文做无边界替换；日常语义中的“对象、条件、原因”等不一定是 Grammar 术语。
- `diagram.text` 必须来自原句；长片段可用明确的省略号节选，不得为追求整齐伪造谓语、补入结论或改变时态。
- 箭头表示阅读顺序、句法连接或真实逻辑关系；词义对比用对照或 `≠`，不要画成原因必然导致结果。
- `memory_tip` 服务于准确回忆：类比只解释本句，不替代定义；词源没有核实就不用“这个词由……演变而来”。

## 内容完成门槛

1. 原文清单与输出逐项对照：无漏句、重复、错序、漏选项，来源定位可追溯。
2. 每句字段完整；译文与解释没有互相矛盾；图中的英文能回查原句。
3. 逐项检查情态、否定、主谓关系、逻辑 Subject、单复数、非谓语与范围限定。
4. `source_note` 与原文分离；Grammar glossary 引用存在，术语与正文一致。
5. PDF 与 HTML 使用同一份核查后的内容；默认自测遮住已有译文并支持单句揭晓，不生成无依据的新答案。
