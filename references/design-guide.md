# Design guide

## 设计目的

把已核查的英语材料制作成可阅读、复习和自测的学习笔记。使用彩色结构标注、箭头指引与适量趣味图解，帮助用户看清“谁做什么、修饰谁、如何推导译文”。本文件规定 workflow 的设计与验证决策，不是固定页数、固定主题或固定成品的模板图库。

## 已验证的排版起点

- PDF：A4 竖版，默认一页一句；正文 10.5 pt，两栏。这个组合是已验证起点，不是压缩所有材料的硬上限。
- 上区依次放来源／编号、明确的 `keyword`、彩色原句、完整译文、句式箭头图。
- 下区左栏放 Sentence structure 与 Vocabulary，右栏放 Exam focus、Pitfalls 与适用的 Source note；Memory tip 放底部独立浅色区。
- 长句、长解析或多项原文注释允许续页；续页标明原句编号与“续”，不得裁剪内容、隐藏溢出或缩小正文来强塞一页。
- 短句保留合理留白；不要为了填满页面扩写重复解释。页边距、行高和卡片间距应以实际渲染结果调整。
- 词义地图按本次材料的词群组织；Grammar glossary 集中置于可快速查找的位置，数量和篇幅随本次内容变化。

## 语法角色色彩

| 角色 | 色值 | 用法 |
| --- | --- | --- |
| Subject | `#2457BD` | Subject 或 Subject 核心片段。 |
| Predicate | `#B84132` | 有限谓语中的核心动词、必要的 Auxiliary verb / Modal verb。 |
| Object / Complement | `#7446A7` | Object、Subject complement、Object complement，按真实结构命名。 |
| Modifier / Adverbial | `#167361` | 修饰语、状语及明确说明的辅助逻辑片段。 |

原句着色、图卡顶线与标签使用一致映射，同时保留文字标签；不得要求用户仅靠分辨颜色理解语法。

同一短语包含多种角色时，优先拆成可读片段；若合并为 `Predicate + Object` 等卡片，标签必须明示包含内容，不能把整段假称为单一角色。

`semantic_modifier` 仅可作为渲染器对 Purpose、Reason、Condition、Connector 等辅助内容的内部归类。需要例外时，在图例说明“绿色也标辅助逻辑关系，具体语法以标签为准”；不能把 `yet` 等 Connector 因为使用绿色就误标为 Adverbial。内部键名不直接展示给学习者。

## 英文卡片与箭头

- 英文优先在空格处换行，保持完整词；不要使用对英语全面逐字符断行的 `word-break: break-all`。
- 先按可用宽度测量，再决定列数和行高；长词或超长片段优先增加宽度、移到下一行卡片或明确节选，不能让字母溢出边框。
- 箭头与卡片保持间隙，不穿越文字；换行后的图可用清楚的转接箭头或编号，不能产生歧义的阅读顺序。
- 图示片段来自原句；长片段节选保留省略标志，完整原句仍在上方。
- 箭头标签必须对应真实关系：Purpose 不等于已实现的 Result，Condition 不等于无条件因果，词义对比不画成事件演进。
- 趣味图解用简洁隐喻支持记忆，如暂停键、倒计时、筛选、逐渐淡化；标出所解释的词义，避免用装饰图占据解析空间。

## 字体与标题防线

- 中文必须落入真实可用、覆盖中文字符的字体，例如经环境验证的 Noto Sans CJK 或 Microsoft YaHei；不能把中文文本交给 Arial 然后假定会正确回退。
- 按实际文本 run 配置字体，混排也逐段检查；Bold 标题和普通正文都要有有效中文字体，不可只修正文。
- 使用本地可用字体或合法打包的字体资源。PDF 检查嵌入与字符覆盖；离线 HTML 不依赖在线字体或 CDN。
- 专项检查 `→`、`↔`、`≠`、智能引号、中英文括号、连字符和中文标题；出现空心方框、替代字符或无声丢字就修复后重新渲染。
- 标题只读取显式 `keyword` 字段；不能取 `vocabulary[0]` 的整段解释，不能把术语替换后的长句误当标题。
- 正文 Grammar 标签用 English，中文解释正常排版；集中 glossary 提供中英对照，避免把每个词的解释都重复塞进图卡。

## PDF 与离线 HTML

- 两种输出共享已验证内容数据与稳定句子编号，避免一份更新后另一份仍使用旧译文。
- HTML 可直接本地打开；内容、脚本、必要样式与图形在文件内或随包提供，不依赖联网请求才能显示正文。
- 搜索至少匹配编号、英文原句、关键词与中文解释；提供清楚的无结果状态和恢复全部内容入口。
- 支持目录／句号跳转、词义地图与对应句子的来回导航；目标 ID 唯一且真实存在。
- 默认自测模式遮住译文，并能单句揭晓、恢复全文；解析保留供对照。不要用删除内容实现隐藏，也不要把答案藏到辅助设备无法访问的位置。
- 交互按钮明确显示当前状态，键盘可操作；缩窄窗口后内容不能互相覆盖。
- 打印样式恢复完整译文与解析，隐藏仅供操作的工具条，处理好卡片和段落跨页；PDF 版仍单独验证。

## 验证顺序与交付门槛

1. 数据完整检查：原始编号、输出编号、译文、解析、图示、附注与 glossary 引用全部对上，无空字段冒充完成。
2. 生成 PDF 后检查全文可提取、页边界和页面数量；页数应由内容产生，不把某次旧页数当目标。
3. 渲染全部页面并检查缩略图，覆盖每页；放大复核最长标题、最长原句、多卡箭头、最密正文、续页、词义地图和全部 glossary 表格。
4. 字体检查确认无乱码、方框、漏字；版面检查确认无重叠、溢出、裁剪、悬空标签或表格内容越界。
5. 断网或拦截外部请求验证 HTML 仍完整可用；实际点击搜索、跳转、单句自测、恢复全文，并检查打印预览。
6. 修复后重渲染受影响页面；共享样式、字体或分页规则变化时，重新检查全部页面与输出编号。
7. 最终交付 PDF 与离线 HTML 的可用文件链接，说明包含哪些学习功能；未实际通过的检查不可声称已验证。
