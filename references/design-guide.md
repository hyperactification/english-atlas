# English Atlas 设计规范

## 阅读层级

新版解决三类实际阅读困难：段落层级难分、学习重点难定位、原词与近义辨析之间缺少明确对应。用空间分组、字级、标签和少量语义色建立顺序，保留全部经过核查的学习内容。

每题按以下顺序排版：

1. 题号、短关键词、来源页码。
2. 完整原句、完整译文、取自原句的拆句图。
3. 分区解析：Sentence structure 使用全宽面板；Exam focus 与 Pitfalls 并排；Memory key 独立全宽。
4. 独立 Vocabulary 词卡；必要时另列 Source note。

词义地图仍由本次词群组织，Grammar Glossary 集中提供中英对照与可回查例号；封面、导航与复习路线服务于整册使用。页数由本次内容和实际排版产生。

## 解析面板与颜色

`atlas_layout.py` 的 PDF 以 A4 竖版为起点，常规正文约 10.7–11 pt，原句约 15.5 pt，词卡头约 14 pt。长结构解析使用全宽，减少窄栏频繁折行；近义辨析保留 10.5 pt 正文与正常行距，以约 4 pt 表格行内边距和约 6 pt 词卡间距减少零散尾页。这些是当前实现的字级关系，不是所有材料的强制字号。HTML 使用相同信息层级，Exam focus / Pitfalls 在窄屏改为纵向阅读。

| 区域 | 文字与浅底 | 用途 |
| --- | --- | --- |
| 正文／Context／替换说明 | 深灰 `#334155`，标题 `#18263D` | 长段解释保持稳定、可读。 |
| Sentence structure | 蓝色标题，浅蓝底 `#F4F7FD` | 定位结构分析，正文仍为中性色。 |
| Memory key | 绿色标题，浅绿底 `#EDF7F3` | 独立记忆提示。 |
| Near synonyms | 蓝色 `#244BC1`，浅蓝表头 | 一眼找到可比较的 English 表达。 |
| Exam focus | 琥珀色 `#8B5700`，浅琥珀底 `#FFF7E6` | 与结构解释区分的考试提示。 |
| Pitfalls | 红色 `#A42D38`，浅红底 `#FFF0F1` | 明确指出错误读法及原因。 |
| Source note | 灰色标题，浅灰底 `#F4F5F7` | 原文瑕疵和建议与正文分开。 |

Grammar 角色色与上述信息区域色是两套用途。角色色只在原句、拆句图及对应图例表达语法含义：

| 角色 | 色值 |
| --- | --- |
| Subject | `#2457BD` |
| Predicate | `#B84132` |
| Object／Complement | `#7446A7` |
| Modifier／Adverbial | `#167361` |

始终同时保留 English 标签，不能要求学习者只靠颜色辨认结构。合并片段如 `Predicate + Object` 必须明示；绿色辅助逻辑片段以 Purpose、Condition、Time 等实际标签为准，不能因颜色相同便改称 Adverbial。内部渲染键不展示给学习者。

## 独立词卡

每项 Vocabulary 使用三层结构：

- **词条头：** 独立浅底、大字 English 词条及序号，不能从整段解释截取标题。
- **Context：** 紧接本句义项、part of speech 与搭配，先解释原词，再给联想。Context 指语境义所在区域，不另加未经来源支持的背景。
- **比较表：** 左列为蓝色 Near synonyms，右列逐项说明差别／替换限制。当前 PDF 列宽约为 34%／66%；HTML 在窄屏把每组表达与对应说明上下排列，保持配对。

一个近义项对应一段清楚的辨析，不拼成难扫描的长串。词性、介词或句式变化需给出可理解的完整短语。没有合适近义表达时，展示 `no_synonym_reason`，不生成占位同义词。正文、近义项、辨析及无近义原因均须进入 PDF 和 HTML。

## 分页与 PLATYPUS 约定

当前 PDF 使用 ReportLab PLATYPUS。先测量每题的原句区、解析面板、完整词卡和 Source note 的真实高度，在保持顺序的合法区块边界上计算所需最少页数，再选择页间高度差较小的分界。内容不固定为一题一页或一题两页；短题保留一页，长题可续页。

`KeepTogether` 使能放下的面板和常规词卡整体移动。Vocabulary 标题与第一张词卡属于同一个区块，避免标题孤立。`layout_report.json` 记录每题的区块高度、计划页数和每页所含区块，便于复核前密后空是否改善。段落采用 `Paragraph` 排版，不按可见高度截断数据。

- 每题独立开始，解析较长时自然续页。页眉重复当前 `id` 与 `keyword`，让读者不依赖翻回上一页判断所属题目。
- 题号与词条序号明确分离：题号用三位编号，词条用 `W01`、`W02` 等。续页顶部另加醒目的 `Q001 keyword / 精讀續頁` 横条，不能只靠极小页眉辨认所属题目。
- 整卡能放下时尽量同页；词卡比较行采用平铺的两列表格，避免把整张近义表嵌入一个不可拆分单元格。长卡通过 `repeatRows=(0,2)` 在续页重复词条头与 Near synonyms 表头，`splitInRow=1` 允许单个长解释正常续页；所有 Context、近义项和辨析连续保留。
- 并排 Exam focus / Pitfalls 若整体高于一页，改为上下排列的全宽表格，允许面板内部自然拆分。其他超过一页的区块也使用自然拆分，并在报告中记录 `natural_split`；不能把它错误报告为已压入一页。
- `repeatRows` 声明本身不证明所有嵌套长行都可拆分。若出现不可拆的嵌套行或 `LayoutError`，修正具体表格拆分实现并重新渲染；不能丢弃行、覆盖剩余段落、隐藏溢出或统一缩小正文。
- 最少复核一次真实续页：核对词条头、接续段落首尾、全部近义行和题号页眉；同样检查 glossary 的跨页表头。
- 允许合理留白；重点比较同一题各页的内容分布。优先移动完整面板／词卡和微调间距，避免首页同时堆满解析与首张词卡、尾页只剩少量内容。不为填满页面重复解释，不以缩小正文字级作为默认解决方案。

## 拆句图、文字与字体

- `diagram.text` 来自完整原句；长片段可用明确省略号节选。箭头表示真实阅读连接，Purpose 不等于已实现的 Result，Condition 不等于无条件因果。
- 英文按词边界换行；窄屏可增加卡片宽度、转为纵向或调整间距，不使用全面逐字母断行。箭头留出间隙，不穿过文字。
- 趣味词义图解释真实词义或对照，不能用未核实词源代替定义；自定义图可用 `illustration.primitives`。
- PDF 使用经验证覆盖中文的字体，标题、Bold 与正文都检查。HTML 样式及图形随文件提供，不依赖 CDN 或在线字体。
- 专项查看箭头、`≠`、引号、括号、连字符及中文标题；方框、替代字符、漏字均需修复。
- 正文 Grammar 用 English，解释用自然中文；集中 glossary 收录实际使用术语与本次例号，不进行无边界术语替换。

## PDF 与离线 HTML 验收

两份输出来自同一份已核查内容。HTML 初始显示译文，开启自测后遮罩译文，可逐句揭晓并重置；正文解析保留。搜索匹配题号、英文、词汇和中文说明；无结果状态、内部跳转和打印恢复全文都须实际测试。

先做来源与内容验证，再渲染和检查实际产物：

1. 核对原始编号、双句、来源页码、完整译文、所有词条及其辨析、Source note、地图范围和 glossary 例号。
2. 运行段落完整性检查，确认 PDF 可提取；重复页眉不能掩盖正文丢段。
3. 渲染并查看全部页面缩略图；放大最长原句、长标题、密集面板、所有续页词卡、地图和 glossary。
4. 查重叠、截字、孤立词卡头、配对失联、表头丢失和页眉误归属；同时并看同一题的首尾页，检查是否前密后空。自动检查通过仍需视觉判断。
5. 拦截外部请求后实际测试 HTML 搜索、自测、跳转、重置、窄屏和打印；共享样式或分页规则变化后重新检查全册。

只报告实际完成的检查与本次真实页数。参考图和小 JSON 是演示，不能替代新材料的导出或验收。
